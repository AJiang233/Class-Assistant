绑定教务系统

课表与学分都在教务系统里，需要先绑定一次登录态。绑定后由服务器代为拉取。

在应用内打开教务系统登录页，登录完成后自动回跳并绑定，最省事。

或者

只能绑定本人教务账号，学号已按当前登录身份锁定。

密码只用于这一次登录：服务端登录成功后只保留会话凭据，不保存也不记录你的密码。

验证码会发到你绑定的手机或邮箱。没收到就点「获取验证码」重发，2 分钟内有效。

不想把密码交给服务端？改成手动粘贴 Cookie

需要用电脑浏览器（手机浏览器做不到），大概花一分钟。

  1. 登录教务系统：在电脑浏览器打开 szjw.njau.edu.cn，用统一身份认证登进去
  2. 按 F12 打开开发者工具，切到 网络 / Network 标签页
  3. 按 F5 刷新页面，等下方请求列表刷出来
  4. 在列表里找一个路径含 /api/ 的请求（名字如 sessionUserInfo），点它
  5. 右侧切到 标头 / Headers，向下滚到 请求标头 / Request Headers
  6. 找到 Cookie: 那一行，复制冒号后面的一整串（很长，全选复制）
  7. 粘贴到下面，点「绑定」
