## 依赖、性能与剩余限制

- 没有新增运行时依赖、数据库表或迁移。测试使用 Node 标准库；README 明确了最低测试版本。
- 日历保持既有每种内容 200 条上限，按窗口内时间先后取数；超过上限的完整导出不在本次范围内。ICS 保持原来的浮动时间格式。
- 受众过滤需按页读取，复杂度与扫描行数成正比；排除组深分页会多读 D1。日历先限定日期窗口，避免无关记录挤占结果，但大量窗口内不可见记录仍增加查询次数；若数据规模增长，应评估查询次数与索引。
- 本地 SQLite 验证实际 SQL 语义，不等价于 Cloudflare 生产配额/网络故障测试。私有教务 Worker 不在公开仓库内，未验证其内部实现。
- Android 编译和设备交互未完成验证；本次 Web 源码修复未引入 Android 改动。仓库 README 中仍有规划模块，本次不将规划状态当作已完成功能。
