# Class Assistant —— 基于 AI Agent 的班级助理

一个面向「班长」角色的 AI 助理系统：把转发通知、活动提醒、同学答疑、材料催收等机械化的班级事务，交给运行在本地服务器上的 AI Agent 自动完成。

## 项目背景

班长的大量日常工作是结构化、可自动化的重复劳动。本项目通过「本地服务器 + Agent 编排 + RAG 知识库 + Web 门户」的组合，让 Agent 承担通知流转、日程提醒与常见问题答疑，既为同学提供更好的服务，也作为个人全栈与 Agent 开发的实践项目。

## 功能规划

- 通知抓取与归档：轮询班级工作群，拉取新通知并结构化归档
- 智能转发：根据通知内容判断是否需要转发到班级群，并支持人工复核
- 知识库问答：爬取学生手册、教务处文件等归档进 RAG，群内 @ 助手即可答疑
- 日程与提醒：生成待办日历，在活动开始/结束时提醒同学
- 个性化门户：Cloudflare 网站 + 账号体系，按角色与报名情况展示个性化日程
- 移动端：安卓 WebView 应用联动网站内容

## 技术架构

| 模块 | 技术选型（规划中） |
| --- | --- |
| Agent 编排 | OpenClaw |
| 消息通道 | 微信本地 API（企业微信 / 个人微信方案待定） |
| 知识库 | 向量数据库 + RAG |
| 本地模型 | 轻量模型（OCR / 上下文压缩 / 查询） |
| 门户网站 | Cloudflare Pages + Workers |
| 移动端 | Android WebView |

## 目录结构（规划）

